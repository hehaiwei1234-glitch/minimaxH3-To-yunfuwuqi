H3 片段整理工具（网页版，在你自己电脑上运行，不上传任何东西）

【它做什么】
H3 的片段里，第一个字之前和最后一个字之后常有几秒“没人说话、画面又几乎不动”的空等。
两个片段接在一起，这两段空等就连成了长停顿。本工具只把这种空等剪掉：
  - 只剪每个片段的开头和结尾，句子中间的节奏一帧不动；
  - 只剪没有人声、画面几乎不动、剪口前后画面接得上的部分，找不到安全的剪口就不剪；
  - 人声前后各多留 0.2 秒；每个片段开头 0.5 秒不剪；原片不会被改。
它不会判断“快”还是“慢”，所以另给每个片段一个“整体加速”选项（默认原速），你需要 1.2 倍的就选 1.2 倍。

【新：自动合成完整成片】
拖进来的片段，除了每个片段各自整理保存（文件名后面加“_整理”），页面上方“整理完自动合成完整成片”（默认打勾）
还会把它们按文件名顺序（01、02、…、10，数字按大小排，不会把 10 排到 2 前面）接成一个完整成片，
存成“输出”文件夹里的“成片_合并.mp4”，页面上直接可以播放预览，并列出合成顺序。
  - 不想放进成片的片段，把那一个片段下面的“放进成片”勾去掉（它自己的“_整理”文件照样会保存）。
  - 成片会重新编码一次（画质约等于原片，声音和画面保持同步）；尺寸、帧率以第一个片段为准。
  - 每次点“全部整理并保存”都会重新生成“成片_合并.mp4”（旧的会被覆盖）；设置没变的片段不会重复处理。

【怎么用】
1. 第一次：确认电脑装了 Node.js（nodejs.org，LTS 版）。
2. 双击 start.cmd。第一次会自动安装组件（约 1 到 2 分钟，要联网），之后几秒就能开。
3. 浏览器会自动打开页面（没打开就手动访问 http://localhost:8765）。
4. 把 H3 出的 mp4 片段拖进页面（一次拖很多个也行）。每个片段会显示：
     原长 → 整理后的长度；绿色条是有人声的部分，橙色条是打算剪掉的空等。
5. 选“剪多少”：稳妥（默认，宁可少剪）／多剪一点／最大胆。拿不准就先“稳妥”。
6. 点“整理这一个”可以先看“原片 / 整理后”对比；满意后点“全部整理并保存”（会同时合成完整成片）。
7. 结果在本文件夹里的“输出”文件夹：每个片段的“_整理”文件，加上一个“成片_合并.mp4”。点页面上的“打开输出文件夹”也行。
8. 用完直接关掉黑色窗口就行。

【注意】
- 剪口处有时画面会有一点点位置跳动（H3 的镜头自己会慢慢推近），多剪一点档更明显；不满意就把那一条的勾去掉，或者回到“稳妥”。
- 没有人声的片段（比如纯环境空镜）默认不处理。
- 如果 npm install 下载 ffmpeg 失败，可以自己装一个 ffmpeg，然后在命令行里先设置环境变量 FFMPEG_PATH 指向 ffmpeg.exe，再运行 node server.js。
