# 插件 v0.8.3.14：集中下载页 + 强制删除（2026-10-15）

压缩包：同文件夹里的 `H3自动短剧_v0.8.3.14_集中下载页与强制删除版.zip`。在 v0.8.3.13 基础上，包含之前所有功能（自动继续、提醒声和音量、下载本集全部镜头），直接装这一个。

## 起因

1. 服务重启或崩溃之后，有的集还留着“提交结果不明”的任务记录，删除时被一句“请先继续核对原任务；提交结果不明时不能删除”拦住，连删除窗口都打不开。
2. 下载成片和分镜头要一集一集点进去找，很费劲。

## 新功能一：删除窗口里的“强制删除”

- 点“删除”后窗口总能打开。如果这一集（或这部剧里的某一集）有“提交结果不明”的镜头任务、或没核对完的生图任务，窗口里会写明有几个，并出现一个**默认不勾选**的选项：“我确认 ComfyUI 里已经没有这集（这部剧）的任务了（比如刚重启或崩溃过），强制删除”。
- 勾上才放行；不勾直接点“确认删除”，会被拒绝并在窗口里说明原因，记录原封不动。
- **只放行这两类检查。**“正在运行 / 排队中 / 准备暂停 / 任务线程还活着”的检查一条也不绕过：这种情况仍要先暂停、等当前任务结束，再删。
- 删除整部剧同样适用。删除某一集后，本集编号保留，之后追加不会复用（我测过：删掉第 1 集后再追加，新集从第 3 集开始）。
- 提醒一句：如果其实 ComfyUI 里那个任务还在跑，勾了强制删除后它跑完的视频没有地方可放，只会白白占一点算力和磁盘；所以只在确认“ComfyUI 已重启、队列已空”时再勾。

## 新功能二：“下载”标签页

顶部导航多了“**下载**”（在“生图工作流”和“设置”之间）。原有页面、按钮都没动，页面里不播放视频。

**列表：**按剧分组（最新建的剧在最上面，最后是“单独制作的集”）；每一集集号从大到小（最新的在最上面）。每一集两项：
- **整集成片**（mp4）：勾选框、大小、单独的“下载”链接；如果只是“未做完的素材合辑”，会写明。
- **分镜头压缩包**（就是原来的“下载本集全部镜头”）：勾选框、镜头数量（几个/共几个）、大小、单独的“下载”链接。分镜头压缩包是点下载那一刻才在服务器上打包的，所以大小是各镜头文件大小之和。

**顶部工具栏：**“已选 N 项 · 共 X GB”，按钮：全选 / 只选成片 / 只选分镜头压缩包 / 只选没下载过的 / 取消全选 / 下载选中的；每个剧还有“本组全选”。

**两个开关：**
- “显示未完成的集（只有已做好的分镜头压缩包）”：默认关，只列已经有整集成片的集；打开后，还没合成、但已有做好镜头的集也列出来，只有分镜头压缩包。
- “显示已归档”：默认关。

**刷新：**只在打开这个页面或点“刷新”时读取一次，不会自动刷新（所以不会增加服务器负担）。

**文件名：**`剧名_第045集_成片.mp4`、`剧名_第045集_分镜头.zip`（集号补零到 3 位；剧名里不能用在文件名里的符号会换成下划线；“单独制作的集”用它自己的标题）。

**批量下载：**点“下载选中的”，浏览器会**一个接一个**下载（约每 1.5 秒触发下一个）。**不做一个超大的总压缩包**（服务器系统盘只有 30G，打总包会塞满）。
- 浏览器第一次可能问“是否允许此网站下载多个文件”，请点“允许”（Chrome、Edge 都可能问一次）。
- 分镜头压缩包要先在服务器上打包，一次只打一个，所以会比成片晚一点才开始下载。
- 同时下载很多个时，网速会被分摊；想稳一点就分几次选。

**“已下载✓”：**只记在**当前这个浏览器**里（换浏览器、换电脑、清除网站数据后会重新显示“没下载过”）。成片重新合成、或分镜头数量有变化后，对应项会重新显示“没下载过”。“只选没下载过的”就是靠它。

## 安装

停掉 ComfyUI → 覆盖 `ComfyUI-H3-AutoDrama-Standalone` → 启动后 Ctrl+F5 → 页面显示“页面 v0.8.3.14 · 后端 v0.8.3.14”。原来的剧、集、视频、设置都保留。如果页面和后端版本不一致，说明 ComfyUI 没有完全重启，请完全停止后再启动。

## 测试了什么、没测什么

- 后端：强制删除的 5 个新测试（预览总能打开且数量正确；不勾选仍被拒绝，传 `"true"`、1 之类不是真正的“是”也被拒绝；“正在运行 / 排队 / 准备暂停 / 任务线程还活着”即使勾选也不放行；整部剧和生图任务；删除后编号保留并能继续追加）；下载清单的 9 个新测试（分组与排序、集号补零和文件名清理、大小、成片文件丢失、归档过滤、找不到所属剧的集、清单接口不改任何记录）；真实 HTTP 下载：成片文件内容与文件名、分镜头 zip 内容与文件名、没有成片／没有镜头时的清楚错误、临时 zip 发送后删除、原来的下载地址不受影响。
- 浏览器（真 Chrome + 假后端）：下载页打开才读取、默认过滤、显示未完成的集、全部选择按钮和合计、单个下载（真的触发下载）、“已下载✓”刷新页面后还在、批量依次下载（每个文件一次请求）、刷新后保留仍存在的勾选、归档开关、读取失败提示后恢复、手机宽度不出现横向滚动；删除窗口：普通删除不出现新选项，有未核对任务时出现、默认不勾、不勾被拒绝窗口不关、勾选后发出强制删除、再次打开自动复位。
- 全套回归结果见聊天里的汇报。
- **没测：**真 GPU 服务器上的真实大文件（几 GB 的成片）下载、真实 Chrome 的“多文件下载”提示和下载列表、真实服务器重启后残留任务记录的强制删除。第一次用请先下一个小文件试试；如果 Chrome 把后面几个下载拦了，页面右上角地址栏会有“已阻止多个下载”的提示，点允许后重新点“下载选中的”即可。
