# outbox：Claude 交付给 hh 的地方

**每个插件版本一个文件夹**，文件夹名 = 压缩包名（版本号 + 这版主要改了什么）。点开文件夹，里面只有两个文件：

- `H3自动短剧_vX.X.X.X_主要功能.zip`（插件本体，要装就下它）
- `日期_插件vX.X.X.X说明.md`（这版怎么用、改了什么、测了什么）

现在有：
- `H3自动短剧_v0.8.3.11_完成提醒声版/`（最新）
- `H3自动短剧_v0.8.3.10_自动重试与追加素材清单修复版/`
- `H3自动短剧_v0.8.3.9_追加剧本与素材勾选修复版/`

其他零散文件（工作流 json、给 hh 的判断说明）直接放在这一层，按日期或名字命名。

《Alpha继兄的笼中吻》的制作稿和说明不放这里，放在仓库根目录的 `Alpha继兄的笼中吻/` 文件夹。

每次交付，Claude 也会在聊天里直接写出关键结论。
