# H3 片段整理工具 v4（2026-10-11）

比 v3 多了什么：**整个 zip 直接拖进来**（可以一次拖好几个，比如第 25–28 集），不用解压、不用自己排顺序。

- 每个 zip 当作“一集”，按集的编号排序，集里的片段按文件名数字排序；
- 点“全部整理并保存”：每个片段存一个“_整理”文件，每一集合一个“成片_<集名>.mp4”，再把所有集合成一个“成片_整批合并.mp4”；
- 结果在工具文件夹的“输出”里，每集一个子文件夹；页面上能直接播放预览；
- 整批总片用整理后的片段重新合成，不是把各集成片再压一遍。

用法：解压到**新文件夹**（别覆盖旧版）→ 双击 start.cmd（第一次要联网装组件，约 1–2 分钟）→ 把插件下载的整集 zip 拖进页面 → 点“全部整理并保存”。详细说明见压缩包里的“使用说明.txt”。

测试：用 hh 传的第 25–28 集 4 个真实 zip（共 42 个片段，原长 210.6 秒）在无头浏览器里跑通：4 个集成片 43.07／55.46／35.71／48.38 秒，整批总片 182.62 秒（四集相加 182.62，一致），1536×576、24fps、h264＋aac；乱序拖入后集的顺序仍正确；页面无报错。云端测试机上整理加合成共约 5 分钟。

**没有在真正的 Windows 上跑过 start.cmd**（已写成 Windows 换行格式）。工具不判断剧情和镜头快慢，这些仍要你自己看。

## 2026-10-15 修复：片段太多时“整批总片”报 spawn ENAMETOOLONG
原因：整批总片一次把所有片段（例如 131 个）塞进一条 ffmpeg 命令，超过 Windows 命令行长度上限。与你删不删“成片_整批合并.mp4”无关——总片每次拖入整理后都会重新合成，不依赖旧文件。修复：超过 30 个片段时先分组合成临时文件、再合成最终成片（临时文件自动清理）。只需把压缩包里的 `lib.js` 覆盖到工具文件夹（或重新解压），重启 start.cmd 即可。总片文件名是 `输出\成片_整批合并.mp4`。

## 2026-10-15 再修：整理中“全部整理并保存”按钮不再变回可点
整理／合成进行中按钮一直保持灰色并显示“正在整理并合成…”，结束后才恢复（以前每整理完一个片段会把它重新点亮，可能被重复点击）。只需把压缩包里 `public\index.html` 覆盖到工具的 `public` 文件夹，刷新网页即可（不用重启）。
