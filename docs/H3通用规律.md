# H3 通用规律（写剧本、写制作稿时直接照着做）

版本 v1.3 · 2026-10-10（在 v1.2 基础上并入“马场一场完整过程”测试的结论，hh 22:40 选定：持续快动作变慢（新增规律 9）、单镜头任务自己切镜（规律 7）、背景串场（规律 5）、过程动作能做（规律 8）；v1.2 是第 6 集视频分析的结论，hh 10:17 选定；v1.1 是第 3 集视频分析的结论，hh 2026-10-09 19:54 逐条选定）。这是主文档；`docs/H3手册.md` 降为归档（原始实验记录，只用来查证据）。下面括号里的 O25、F11 之类编号，指归档手册里对应的条目；"第 3 集"的证据在 `Alpha继兄的笼中吻/第03集/第03集_视频分析.md`。

## ★ 最高优先级：先读完这一节，再做任何事（新聊天必读）

**这一节高于一切：高于聊天里的临时安排、高于说明书里的其他描述、高于“先记下来再说”的冲动。与它冲突时，以它为准。这是 hh 使用 Claude Pro 做这件事的目的所在。**

### 1. 这份文档为什么存在

hh 在做 AI 短剧生产线，视频由 H3 生成。H3 有自己的脾气：很多写法按常识没有任何毛病，H3 却理解不了、做不出来或做歪（例如：写“没有镜子”，镜子照样出现；写“一只手从画面边缘伸进来”，那只手就变成无主的手）。

**这份文档唯一的价值：把 H3 的这些规律归纳成一套通用的、可靠的写法，让以后任何一个新聊天里的 Claude 写剧本和制作稿时，直接按 H3 的方式写，一次就尽量写对**，而不是每个片段出了问题再各个击破。

### 2. 里面记什么（只记这三类）

1. **H3 的通用规律（最重要）**：H3 对提示词、开场图、声音的反应方式。一条规律必须能解释多个不同的案例；每条写成：**规律｜依据（合并了哪些案例、样本数 n）｜把握程度｜该怎么写**。
2. **影响写稿的插件事实**：要短，只留会改变“怎么写”的。
3. **待验证的假设**：单独放、要短；不混进规律里。

### 3. 不记什么（这些就是“屎山”的来源）

- 单个片段发生了什么的流水账；只在一个片段里出现一次的现象。除非它是某条通用规律的例子，那样只在那条规律的“依据”里留一笔。
- Claude 自己的失误记录、道歉、过程感想（写进 `docs/项目进度与实验记录.md`，不写进这里）。
- 没验证的猜测不得写成规律。
- 重复的内容：新证据并入原来那一条，**不新增条目**。

### 4. 怎么更新（流程，必须照做）

1. 有新结论时，**先在聊天里向 hh 列出问题点**，逐条标明归属：① H3 的理解问题（最有价值）② Claude 自己的缺陷 ③ 插件软件本身；写明证据等级和样本数 n。
2. 把单点现象**归纳成通用规律**。门槛：能解释多个不同的案例，或至少有 3 次一致的观察；达不到的只进“待验证”。
3. **hh 点头之后才能改这份文档，没有点头不准改。** 合并时优先并入已有条目；一轮分析结束后一次性改，不要每回复一次就改一次。
4. 改完自查：有没有把流水账带进来？有没有重复？文档有没有无谓变长？
5. 归档手册 `docs/H3手册.md` 只作查证据用，不再往里添新条目；是否整理它，先问 hh。

| 9 | **持续的快速循环动作（奔跑、跑动）会被拉成慢动作；一次性的爆发动作基本正常。** 声音是正常速度，画面却慢几倍，嘴和身体对不上节奏 | 两个骑马奔跑的任务：蹄声节奏正常（每秒 8–10 声），画面里马腿动得很慢，相邻 1/8 秒的两帧几乎一样；hh 看着要加快约 4 倍才正常，而同一画面里的人没有慢 4 倍，整体加速仍然怪（**“4 倍”只来自 hh 的观看**，我用软件量腿的节奏不稳，没量出数）；两个“马人立”的任务：抬起后的姿势保持了整个任务，真实动作只有 1–2 秒；反面：一次性的爆发（捏碎杯子、一击泼出酒）在约 1 秒内完成，动作量是平时的 3–8 倍，但做完后画面又定住；普通人体大动作（上马、挥臂）我目测比正常慢约 1.5–2 倍 | 中偏弱：奔跑 n=2、人立 n=2、爆发 n=2；人体大动作只是目测 | **不要让奔跑、人立成为镜头的主体**；一定要拍，用短镜头，或只在没有台词、没有人脸特写的镜头里后期整体加速；要“快”就写一次性爆发（猛地、一下），放在任务前 1–2 秒；大动作写成一个连续动作加明确的结束姿势；任务缩短能否让动作变快，见待验证 H21 |

## 二、影响写稿的插件事实（只留会改变“怎么写”的）

- **成片是各任务按顺序硬切拼接，没有转场**（17 段相加 109.419 秒，成片 109.455 秒，O40）。每个任务要自己把场景交代清楚。
- **英语一句台词 ≤7 个单词。** 插件按每秒 2 个英语单词估算，格式检查会卡对白时间（F7）。时长按 17k+5 帧取整，5 秒实际 5.167 秒，6 秒实际 6.583 秒。**有台词的任务保留 H3 的原始尾部（比计划长 0.17–0.58 秒），没台词的任务裁成刚好 5.0 / 6.0 秒（第 3 集 14 个片段），所以成片总长比计划长。**
- **追加后续稿：** `style`、同名素材、同名角色必须逐字相同，否则整批被拒（F11）；写成 `generate` 的素材每次都重新生成，想沿用旧人物要写 `source`（F12）。
- **“承接前段”（`depends_on_previous`）：** 把上一段最后一帧交给下一个开场图做位置参考。界面里没有开关，只能写在稿子里；缺省是开；**重做一段，会连带重做后面承接它的段落**（F13）。**实测作用（第 3 集 8 次承接）：同一批人、同一场戏的相邻两段，姿势、站位、光线接得上（5/5）；1 次同人同房间但镜头从广角换成侧面特写，房间大体接上；接不上的 2 次，都是“另一个人被移出画面、改成单人＋视线看画外”的连续段，房间里冒出原来没有的门或窗帘（n=2，原因不明）。不承接的段落，只要用同一张场景素材并写固定布局句，房间也基本一致（4 段）。结论：承接前段保的是姿势和位置的连续，不是房间一致。**

## 三、待验证（不是规律，别当事实）

- **H11** 没台词的片段写"完全没有人声"能压住杂音：第 3 集 7 个没台词的片，语音识别都没识别出词，hh 暂未听出问题；但没有“不写这句”的对照，只算倾向（n=7，无对照）。
- **H12** 切镜后写出房间固定物能保住背景：没验证。
- **H19** 画外目标改写成“视线落在画面里的东西或地面上”，或写出画外人物的衣着、发色，能避免冒出陌生人：没单独验证（“让对方入画”这一种已验证 1/1，见规律 3）。
- **H21** 任务越短，持续的快动作越快、越能在任务时间内做完：同一个奔跑、同一个“人立”各用 2、3、5 秒写一遍，看动作是否被压快（时长测试，hh 10-10 22:40 同意开始）。
- **Killian 的英语读音：** 没测（Q19）。
