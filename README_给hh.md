# 给 hh：这个仓库怎么用

这份只给你看，新会话不需要读。

## 一、上传已经由 Claude 完成，你不用再传

备份包已经由 Claude 推送到本仓库的 `main` 分支（2026-10-08）。`inbox` 和 `outbox` 文件夹也建好了。

## 二、你要自己做的一件事：改成私有

仓库现在是**公开**的（任何人都能看到），里面有你的原创剧本，请尽快改成私有：

仓库页面 → Settings（设置）→ 拉到最下面 Danger Zone（危险区）→ Change visibility（更改可见性）→ Make private（设为私有）。

## 三、开新聊天

1. 在 Claude Code 网页版选这个仓库，分支选 `main`。
2. 模型选 **Sonnet 5.5**（默认的 Haiku 5.5 偏弱，这个项目要认真读文件、做分析）。Opus/Fable 更强但更费额度，先用 Sonnet。
3. 第一句话复制这段：

> 请先完整读 CLAUDE.md，再读 docs/项目进度与实验记录.md 和 docs/H3手册.md。读完用三句话告诉我：我们的目的是什么、现在做到哪、下一步是什么。说完等我指示，不要开工。

4. 它答的三句话要对得上：目的是“写出适合 H3 的剧本，让片段直接可用”；现状是“试验结束，画面问题基本解决，台词时间没解决”；第 1 集制作稿已经交付给你；下一步是你跑完、把视频传到 `inbox`，它分析后再出下一批。不对就纠正它。

## 四、以后怎么交换文件

- **你给它：** 进入仓库的 `inbox` 文件夹 → Add file → Upload files → 拖入文件 → Commit changes。然后在聊天里说“inbox 有新东西”。视频请打成 zip（单个文件不要超过 25 MB，超过就分成几个 zip）。
- **它给你：** 它把文件放进 `outbox`，并在聊天里直接写结论。你在仓库里点开文件，右上角有下载按钮。如果它推送的不是 `main` 分支，它会告诉你分支名，并问你要不要合并到 `main`。
- **手册：** 以后以仓库里的 `docs/H3手册.md` 为准。想自己备份，就定期下载这个文件。Claude 文档里那份我不再更新。

## 五、额度提醒（$100）

我没法预测具体会花多少，请在账户的用量页面看。省额度的办法：一件事一个会话；会话变得很长时，让它先把进度写进仓库（更新 `docs/项目进度与实验记录.md`），再开新会话。

## 六、没放进仓库的东西

- 你的视频（太大，你本地也有）。
- `NG经验总结.zip`（24 MB）和完整插件 `V3ComfyUI-H3-AutoDrama-Standalone.zip`（116 MB）。
- `project.json`、`series.json`（项目全部记录，较大，需要时再传到 `inbox`）。
- 语音识别模型（1 GB）。新会话运行 `tools/setup_asr.sh` 会自己下载。
