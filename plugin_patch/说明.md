# 插件补丁（存档）

## 先看结论

- **“保留尾部”补丁现在不需要。** 插件 v0.8.3.6 官方包（`reference_from_hh/H3自动短剧_v0_8_3_6_…zip`）已自带尾部保护，它的 README 里写了。判断尾部有没有保留：含台词的 6 秒任务，输出 6.583 秒（=158 帧）就是保留了；被切成 6.000 秒就是没保留。
- **“重试诊断文字”补丁没有应用过，要不要打，先问 hh。**

## 文件

| 文件 | 是什么 | 适用的版本 |
|---|---|---|
| `engine.py`、`media_tools.py` | 我给 hh 当时用的较早版本打了“保留尾部”补丁后的完整文件（`KEEP_ALIGNMENT_TAIL=True`、`keep_full`） | v0.8.3.6 **之前**的文件。直接覆盖到 v0.8.3.6 会降级，**不要覆盖** |
| `keep_tail_engine.diff`、`keep_tail_media_tools.diff` | 上面两个补丁的差异 | 同上 |
| `fix_retry_note_runtime.diff` | 修手册 F3：自动重试时，应用把中文诊断文字（“修正视频/对白核对发现的问题…”）塞进视频提示词，H3 会把它念成乱码。改 `production_draft/runtime.py`，让自动诊断不进提示词，只有人手写的反馈才进 | **v0.8.3.6**。已用 `patch -p1 --dry-run` 验证能干净套用 |

## 怎么套用 `fix_retry_note_runtime.diff`

在包含 `ComfyUI-H3-AutoDrama-Standalone` 文件夹的那一层目录里运行：

```
patch -p1 < fix_retry_note_runtime.diff
```

套用前先备份原文件。目前靠“视频/对白共用次数 = 1”绕开这个问题，所以不是必须。
